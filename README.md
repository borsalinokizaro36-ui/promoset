# Промосеть на GitHub Pages + Supabase

Сайт (с настоящей картой OpenStreetMap) лежит на GitHub Pages, данные, фото и вход — в Supabase. Оба сервиса бесплатны на старте.

Файлы:

| Файл | Что это |
| --- | --- |
| `index.html` | Само приложение |
| `adapter.js` | Связь с Supabase: данные, фото, вход |
| `config.js` | Настройки: адрес и ключ Supabase, карта |
| `setup.sql` | Подготовка базы в Supabase (запускается один раз) |

## Шаг 1. Supabase — база и фото (≈10 минут)

1. Зарегистрируйтесь на supabase.com и нажмите **New project**. Задайте название (например, promoset), пароль базы (сохраните его) и регион **Central EU (Frankfurt)**.
2. Когда проект создастся, откройте слева **SQL Editor** → **New query**, вставьте весь текст из `setup.sql` и нажмите **Run**. Должно появиться «Success».
3. Слева **Authentication** → **Sign In / Providers**: оставьте вход по Email и **выключите «Allow new users to sign up»**, чтобы посторонние не могли зарегистрироваться.
4. **Authentication** → **Users** → **Add user** → **Create new user**: впишите почту и пароль для каждого, кто будет работать в приложении, и поставьте галочку **Auto Confirm User**.
5. **Project Settings** → **API**: скопируйте **Project URL** и ключ **anon public**.

## Шаг 2. Настройки

Откройте `config.js` в любом текстовом редакторе и замените:
- `https://ВАШ-ПРОЕКТ.supabase.co` на ваш Project URL;
- `ВАШ-ANON-КЛЮЧ` на ключ anon public.

Ключ anon можно хранить открыто — так задумано в Supabase. Данные защищены входом по паролю и правилами доступа из `setup.sql`.

## Шаг 3. GitHub Pages — сайт

Уже сделано: файлы лежат в этом репозитории, GitHub Pages включён (Settings → Pages → ветка **main**, папка **/ (root)**).
Сайт: **https://borsalinokizaro36-ui.github.io/promoset/**

Чтобы вписать настройки, откройте `config.js` здесь на GitHub → значок карандаша (Edit) → замените два значения → **Commit changes**. Через 1–2 минуты сайт обновится.

Входите с почтой и паролем из шага 1.

## Как это работает

- Код сайта в публичном репозитории виден всем, но данные без входа недоступны.
- Карта OpenStreetMap включается при выборе округа. Бесплатная карта OSM годится для небольшой нагрузки. При постоянной коммерческой работе подключите поставщика карт (MapTiler, Stadia Maps): для этого достаточно поменять `tiles.url` в `config.js`.
- Ссылки на фото длинные и случайные. Посторонний их не угадает, но тот, кому переслали ссылку, фото откроет.
- Бесплатного тарифа Supabase хватит примерно на 500 МБ данных и 1 ГБ фото (это тысячи фотоотчётов). Если проект неделю никто не открывает, Supabase его приостанавливает. Возобновить можно одной кнопкой в панели, данные сохраняются.

## Обновление

Чтобы обновить приложение, загрузите на GitHub новый `index.html` поверх старого. `config.js` при этом менять не нужно.
